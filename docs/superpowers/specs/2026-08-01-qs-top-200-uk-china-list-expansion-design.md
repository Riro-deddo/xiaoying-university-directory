# 小英高校百科：QS 前 200 英国大学中国院校 List 扩充设计

日期：2026-08-01

## 目标

把当前三所大学的样板目录扩充为覆盖 QS 2027 世界大学排名前 200 中全部英国大学的免费公开工具。网站集中展示大学官网面向中国本科背景申请者发布的院校 List、分档、均分和适用范围，并支持从英国大学和中国本科院校两个方向搜索。

本工具提供官方信息导航和证据状态，不判断申请资格、录取概率或最终录取结果。

## 已确认的产品原则

- 覆盖范围以 QS 2027 官方排名中世界前 200 的英国大学为准。
- 只把英国大学官网、大学官方 PDF 和大学官方学院页面作为事实来源。
- 有全校公开 List 时收录院校名称、分档、均分、申请季和适用范围。
- 只有学院或专业公开 List 时标记为“部分学院公开”，不得扩展为全校规则。
- 没有公开 List 时仍收录大学及其官方中国学历或均分要求，并标记“未发现公开 List”。
- “公开 List 中暂未找到”不等于不能申请；页面不得输出“可以申请”或“不能申请”。
- 中文解释不能冒充官方原文；无法完全对应时保留官方英文术语。
- 自动化处理重复劳动，异常才需要人工查看。

## 用户体验

### 搜索英国大学

用户输入英国大学中文名、英文名或常用简称后，看到：

- QS 2027 排名；
- 公开状态；
- 官方中国申请要求；
- 全校或学院级分档；
- 分档对应的中国本科院校；
- 均分要求及适用学院、专业和申请季；
- 最近成功检查日期；
- 官方原文链接。

### 搜索中国本科院校

用户输入中国本科院校中文名、英文名或已登记别名后，看到 QS 前 200 英国大学的证据结果：

1. 官方全校 List 中明确找到；
2. 仅在部分学院 List 中找到；
3. 官方公开 List 中暂未找到；
4. 该英国大学未发现公开 List；
5. 官网更新待确认；
6. 来源暂时无法检查。

匹配结果展示官方分档、均分、适用范围和来源，不推断录取资格。

## 数据设计

数据分成四层，避免自动任务改写人工说明。

### 大学目录

`src/data/universities.json` 保存相对稳定的人工登记信息：

- 大学标识、中英文名称和别名；
- QS 版本和名次；
- 官网来源标识；
- 对没有公开 List 的中性说明。

### 来源登记表

新增来源登记表，保存：

- 官方 URL、来源类型和适用申请季；
- 全校、学院、专业或课程范围；
- HTML、PDF 或只检查链接的解析模式；
- 确定性的选择器、标题锚点或表格列映射；
- 合理的记录数量范围和其他结构校验条件；
- 是否允许自动提取。

每个来源必须显式登记；系统不在互联网上自动猜测“正确页面”。

### 自动生成的申请事实

`src/data/generated/` 保存从官方来源确定性提取的事实：

- 中国本科院校的官方名称；
- 官方分档名称和保留的英文术语；
- 均分或成绩区间；
- 适用范围与申请季；
- 来源标识、提取时间和内容指纹。

自动生成文件不得保存完整网页正文。

### 中国本科院校规范表

保存规范名称及公开可验证的别名，用于把中英文名称、旧称、空格和标点差异归并到同一搜索项。无法可靠归并的名称保持独立并标记待确认，不做模糊合并。

## 复用的开源组件

- Mozilla Readability：提取普通官方网页的主要正文。
- PDF.js：读取大学官方 PDF 中的文本和表格文本层。
- Lychee：检查官方链接、重定向和失效状态。
- GitHub Actions：每日调度、数据校验、构建、异常 Issue 和 Pages 发布。
- 项目现有的内容指纹、状态记录、Astro 静态构建和搜索逻辑继续复用。

不使用需要常驻服务器的 changedetection.io，也不依赖付费抓取、翻译、数据库或人工智能 API。

## 自动化数据流

每日 GitHub Actions 按以下顺序运行：

1. 读取显式登记的官方来源。
2. 以保守速率逐一请求，每个来源每天最多检查一次。
3. 记录 HTTP 状态、最终 URL、ETag、Last-Modified、内容指纹和检查时间。
4. HTML 使用 Readability 和来源专属规则解析；PDF 使用 PDF.js 和来源专属规则解析。
5. 把结果规范化为院校、分档、均分、范围和申请季事实。
6. 运行结构、数量、唯一性、范围和反向搜索校验。
7. 与上一版可信数据比较。
8. 校验通过时更新自动生成数据，运行完整 CI，并只发布刚通过 CI 的同一提交。
9. 校验失败时保留上一版可信数据，更新状态为“官网更新待确认”，并创建包含来源和失败原因的 GitHub Issue。

短暂网络错误只更新来源状态，不删除已确认事实。

## 异常处理

- 页面无法访问：保留旧数据，显示“来源暂时无法检查”。
- 页面重定向：记录最终 URL；来源仍属同一大学且校验通过时显示跳转状态。
- 内容改变但解析正常：生成差异，校验通过后自动更新。
- 记录数量异常减少、分档消失或页面结构突变：停止该来源更新并创建 Issue。
- 官方 List 中没有某所中国院校：显示“公开 List 中暂未找到”，不推断申请资格。
- 没有公开 List：显示官方中国学历或均分要求以及“未发现公开 List”。
- 学院级规则：只在该学院范围内返回匹配，不推广到其他学院。
- 申请季过期：保留来源历史信息但不作为当前匹配结果，优先寻找当前申请季官方来源。

## 抓取与合规边界

- 只访问无需登录的公开大学官网和官方文件。
- 不绕过验证码、登录、付费墙、访问控制或网站技术限制。
- 不访问申请系统，不收集个人数据。
- 不镜像网页或 PDF，只保存检索所需的结构化事实、短标签和来源链接。
- 对明确禁止自动访问或持续拦截的来源停止自动提取，只保留人工登记的官方入口。
- 使用可识别的请求标识、低频串行访问和合理超时，避免给大学网站造成负担。

## 测试策略

### 数据测试

- QS 版本、排名、大学唯一标识和全部目标大学覆盖测试；
- 来源必须属于已登记大学且使用允许的官方域名；
- 分档、均分、范围、申请季和来源引用的结构校验；
- 中国本科院校规范名和别名冲突检测；
- “未发现”和“不能申请”等禁用推断用语回归测试。

### 解析测试

- 每种 HTML 表格、列表和正文模式保存最小官方样本测试；
- 每种 PDF 版式保存最小文本层样本测试；
- 页面结构变化、空结果、数量骤减和重复记录测试；
- 网络错误、重定向、超时和无文本 PDF 测试。

测试样本只保留解析所需的最小片段，不保存完整受版权保护页面。

### 搜索和页面测试

- 英国大学中英文名及简称搜索；
- 中国本科院校中英文名、别名、空格和标点归一；
- 全校与学院级匹配范围隔离；
- 六种证据状态和中性中文文案；
- 手机与桌面布局、键盘操作和无结果状态；
- GitHub Pages 子路径链接与方法页面。

### 发布测试

- 只有 CI 成功才能触发 Pages；
- Pages 必须检出触发 CI 的同一提交；
- 旧工作流完成不得覆盖新版本；
- 异常来源不得覆盖上一版可信数据。

## 分阶段交付

1. 从 QS 2027 官方排名确定世界前 200 的全部英国大学，并为每所大学登记至少一个官方中国要求入口或明确的未公开状态。
2. 引入来源登记表、Readability、PDF.js 和 Lychee，完成确定性抓取框架。
3. 优先解析有公开全校或学院级 List 的大学，生成中国本科院校规范表。
4. 上线中国本科院校反向搜索和证据状态结果。
5. 接入每日自动更新、异常 Issue 和可信旧数据回退。
6. 完成全量验收后替换当前三所大学样板说明。

## 验收标准

- QS 2027 世界前 200 英国大学全部出现在目录中。
- 每所目标大学至少有一个官方中国要求来源，或有可解释的“未发现公开 List”记录。
- 所有已登记公开 List 均能生成分档事实或明确进入待确认状态。
- 英国大学和中国本科院校双向搜索可用。
- 每个匹配结果可追溯到官方来源、适用范围、申请季和最近成功检查时间。
- 一次网络错误或解析异常不会删除或覆盖上一版可信数据。
- 完整测试、Astro 类型检查和静态构建通过。
- 线上运行不需要用户电脑、付费 API、服务器、数据库或付费域名。

## 不在本阶段范围内

- 录取概率、选校建议或“保底/冲刺”判断；
- 个人成绩计算、账号、收藏和申请进度管理；
- 全英国大学或 QS 200 名以外大学；
- 所有具体硕士课程的逐专业申请要求数据库；
- 运行时机器翻译或人工智能摘要；
- 复制或重新发布大学网页和完整 PDF。

## 成本

项目继续使用公开 GitHub 仓库、GitHub Actions 和 GitHub Pages。设计不引入付费服务；持续零成本仍取决于 GitHub 对公开仓库当时的免费政策与额度。
