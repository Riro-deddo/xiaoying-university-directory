# 小英高校百科：硕士奖学金官网入口设计

日期：2026-08-31

## 目标

在现有 101 所英国大学目录中，为每所大学增加经过核验的官方硕士奖学金入口状态；找到公开入口时帮助用户从院校信息直接进入大学官网，未找到时诚实显示非点击状态。

本次功能定位为“官方入口导航”，不是站内奖学金数据库。网站不复制或维护每项奖学金的名称、金额、开放状态、申请时间、截止日期或申请条件。

## 已确认的范围

- 仅面向硕士阶段，不收录本科或博士专属资助。
- 硕士范围包括 MA、MSc、MBA、LLM、MEd、MPH、MRes，以及可以独立授予的 MPhil。
- 不包含本科入学体系中的本硕连读 MEng、MSci，不包含 PGCert、PGDip，也不包含 PhD、DPhil、EngD 或博士 studentship。
- 官方页面只写 `postgraduate` 时，必须确认该页面明确包含硕士，不能把博士专属页面当作硕士入口。
- 页面同时覆盖硕士与博士时可以作为兜底入口，但界面必须标注“研究生资助官网（含硕士，请筛选）”，不能暗示页面只包含硕士。

## 界面方案

- 保留现有六列桌面排版、移动端卡片排版、大学名称、QS／THE 排名、中国规则状态、规则范围、中文摘要、List、筛选和排序。
- 在现有“来源 / 操作”区域中增加“查看硕士奖学金官网”入口。
- 新入口与现有中国硕士入学要求来源、现有“查看全部硕士课程”入口并列，不能覆盖、移动或合并既有功能。
- 标准入口使用主文案“查看硕士奖学金官网”，次级文案根据来源显示“官方奖学金目录”“官方奖学金搜索器”或“研究生资助官网（含硕士，请筛选）”。
- 使用现有外链视觉语言，不增加奖学金卡片、金额标签、截止日期状态或新的表格列。
- 桌面端在“来源 / 操作”区域纵向排列操作；移动端继续使用单列、自动换行，不能出现横向滚动或单字竖排。
- 每所大学仍渲染一个奖学金 action root；`available` 组渲染一个直接外链或多入口折叠，`no-public-entry` 组只显示非点击文案“未发现公开硕士奖学金入口”。

## 多奖学金与多入口处理

一个学校有多个奖学金时，不在本站逐项展开。标准做法是使用大学官方奖学金目录、Funding 页面或奖学金搜索器，由大学官网承载所有具体项目。

如果大学没有统一目录，但存在多个互补的官方分类入口：

- 每所大学最多保留 3 个入口，只按来源类别组织，例如校级资助、学院资助、国际学生资助；
- 不把每个具体奖学金拆成单独入口；
- 默认显示“查看硕士奖学金官网（N 个入口）”；
- 用户点击后在原“来源 / 操作”区域展开分类入口；
- 展开项保留官方链接、页面范围和入口类型；只有入口异常时才增加简短警告，不常驻显示检查时间；
- 多入口折叠与中国规则的多来源折叠相互独立，不能嵌套或混用数据。

## 数据结构

- 新建独立的硕士奖学金入口数据集，以大学稳定 ID 为键，恰好覆盖当前 101 所目录大学。
- 每所大学对应一条带组级 `entryState: available | no-public-entry` 和 `reviewedAt` 的记录。
- `available` 记录包含 1 至 3 个官方链接；`no-public-entry` 记录必须包含 0 个链接，表示人工审查后没有发现可诚实呈现的公开硕士奖学金入口。
- 每个链接至少包含：稳定来源 ID、大学 ID、官方 URL、中文入口标签、页面范围、入口类型、是否需要用户在官网继续筛选、核验日期、页面身份文字锚点和来源状态 ID。
- 入口类型限定为：硕士奖学金目录、硕士奖学金搜索器、包含硕士的研究生资助目录、官方分类资助入口。
- 奖学金入口与中国规则来源、硕士课程入口分开建模，不能进入中国规则状态统计、公开 List 统计或硕士课程入口计数。
- 构建时按大学 ID 连接数据；缺失大学、重复大学、状态与链接数量不匹配、超过 3 个链接或来源 ID 冲突均使测试失败。

## 官网核验标准

- 必须为 HTTPS 官方大学域名，或由大学官网明确跳转的官方资助平台。
- 优先顺序为：硕士专属目录或搜索器、postgraduate taught 资助页、明确包含硕士的研究生综合资助页、互补的官方分类入口。
- 页面必须能够继续找到硕士奖学金或硕士资助，不能只指向大学首页、新闻稿、博客、第三方聚合站或本科／博士专属页面。
- 不使用单个奖学金详情页代替学校的完整目录；只有在没有统一目录且该页面属于必要的官方分类入口时才可作为补充来源。
- 逐校记录最终 URL、页面标题和能够证明其资助入口性质及硕士覆盖范围的文字锚点。
- 如果暂时无法确认一个页面覆盖硕士，保留为审查候选，不进入正式入口数据。
- 如果完成官网审查后仍未发现公开硕士奖学金入口，研究表以 `no-public-entry` 行保留官方负面证据页、稳定 evidence ID、页面标题和两个文字锚点；该证据页不进入生产 action links。

## 每日巡查与人工复核

- 复用现有每日来源巡查，仅检查 `available` 组中可点击奖学金入口的可访问性、最终跳转地址和页面身份文字锚点。
- `no-public-entry` 组没有每日链接巡查目标，只参与每年申请季前的人工复核。
- 每次成功或失败尝试都写入当日审计；普通且无变化的成功检查不产生新的持久化状态提交，也不抓取奖学金名称、金额、开放状态、申请时间、截止日期或条件。
- 页面可访问但内容指纹或身份锚点发生变化时，将来源标记为“待复核”，保留最后一次确认的正式入口，不自动改写或删除。
- 403、404、429、超时和 5xx 继续使用现有连续失败阈值、Issue 去重和非阻塞策略，不能因为单个外部网站异常使整个每日巡查失败。
- 每年申请季前进行一次人工全量复核，重新确认 101 所大学的入口状态；可用组继续覆盖硕士资助，无公开入口组重新搜索是否出现新入口，并按审核结果更新组级状态、日期和正式来源。

## 用户提示

- 入口只帮助用户到达大学官方资助页面，不代表奖学金正在开放，也不代表用户符合条件或能够获奖。
- 具体项目、金额、资格、申请方式和期限全部以大学官网当时显示的信息为准。
- 当入口指向同时包含其他学历层级的综合页面时，界面明确提醒用户继续筛选硕士。
- “未发现公开硕士奖学金入口”只表示在最近一次人工复核中未找到合格的公开入口，不表示学校必然没有任何内部或非公开资助。

## 测试与验收

- 数据测试：101 条大学记录一一对应；每条具有明确状态和复核日期；可用组含 1 至 3 个链接，无公开入口组含 0 个链接；可点击来源 ID 和 URL 无非法重复，且全部为 HTTPS 及允许的官方域名。
- 范围测试：禁止本科／博士专属入口；综合研究生页面必须声明需要筛选，并具有证明硕士覆盖范围的文字锚点。
- 构建测试：每所公开大学都连接一个奖学金状态组；可用组连接奖学金入口，无公开入口组保持零链接；中国规则来源、硕士课程入口和现有统计完全不变。
- 交互测试：单入口直接外链；多入口默认折叠、可由键盘展开；无公开入口显示非点击文案；展开后不丢失、不重复。
- 回归测试：现有六列标题、排名排序、筛选、中文院校反查、List、中国规则摘要、硕士课程入口和每日巡查语义不变。
- 浏览器验收：桌面检查普通单入口院校和曼彻斯特大学；390px 手机检查三类操作、双重多来源折叠、自动换行、无重叠和无横向溢出；控制台无错误或警告。

## 不在本次范围

- 在本站列出每个奖学金。
- 维护奖学金金额、期限、开放状态、申请方式或资格摘要。
- 根据国籍、院校背景、专业或成绩自动匹配奖学金。
- 使用第三方奖学金聚合网站补足数据。
- 更改任何中国院校规则、成绩要求、QS／THE 排名或硕士课程入口。
