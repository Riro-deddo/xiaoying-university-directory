# 小英高校百科：全英 QS 院校目录与 THE 辅助排名设计

日期：2026-08-08
状态：已完成产品与视觉方案确认，等待书面规格复核

## 1. 目标

在不改变“小英高校百科”核心定位的前提下，将当前 QS 前 200 英国院校范围扩展为当期 QS 世界大学排名中出现的全部英国院校，并为相同院校补充 THE 世界大学排名作为辅助信息。

网站的核心仍然是帮助中国学生查找英国大学公开的中国本科院校清单、分档、成绩要求、适用范围和官方来源。排名只用于认识和筛选学校，不用于判断申请资格、录取概率或推荐顺序。

## 2. 已确认的范围

- 主目录收录当期 QS 世界大学排名中出现的全部英国院校，不再限制在世界前 200。
- THE 世界大学排名作为主目录中相同院校的辅助字段；不会因为某校只出现在 THE 而自动扩充主目录。
- 首次扩展以 QS 2027 世界大学排名和 THE 2026 世界大学排名为数据基线；以后按各自的新榜单年份独立更新。
- QS 与 THE 显示各自真实榜单年份，不把不同发布周期伪装成同一年。
- 新进入 QS 英国范围的院校在年度更新时加入；已经收录但后来未出现在当期 QS 的院校继续保留，并标记“当期未上榜”。
- 没有公开中国院校清单的学校仍然进入目录，明确标注“未发现公开清单”或更具体的证据状态。
- 已有中国院校清单、成绩要求、来源链接、折叠展示、中文搜索和每日审查功能全部保留。
- London Business School（LBS）作为“特色院校”保留，不参与 QS/THE 综合大学排序。
- 本次不扩展全部硕士专业，不新增选校推荐、录取概率、账号、收藏或收费功能。

## 3. 产品原则

1. 中国院校规则优先于排名：清单状态、适用范围和成绩要求在视觉上比排名更突出。
2. 证据优先于推断：只展示可追溯到大学或学院官方页面的事实，不把“未找到”解释为“不能申请”。
3. 排名只作参考：不使用排名生成“冲刺”“保底”或申请资格判断。
4. 年份透明：QS、THE、中国院校规则和来源检查各自保存时间信息。
5. 自动审查不冒险改写：每日任务发现变化时保留上一版可信内容，并进入复核流程。
6. 免费且静态：继续使用公开 GitHub 仓库、GitHub Actions 和 GitHub Pages，不引入付费 API、常驻服务器或数据库。

## 4. 页面设计

### 4.1 顶部范围说明

首页说明调整为：目录覆盖当期 QS 世界大学排名中的全部英国院校，并叠加 THE 世界大学排名；网站重点仍是公开的中国本科院校清单与申请要求。

范围说明中同时注明：

- QS 和 THE 是不同机构、不同年份的榜单；
- 排名不代表申请资格；
- 中国院校规则以大学及具体课程官网为准。

### 4.2 筛选与搜索

保留现有中英文搜索，并支持：

- 英国大学中文名、英文名和常用简称；
- 中国本科院校中文名、英文名和已确认别名；
- “有全校公开清单”“部分学院公开”“未发现公开清单”“待复核”“特色院校”等状态筛选；
- QS 排名、THE 排名和学校名称排序。

排名筛选不是默认入口，避免网站退化为普通排名表。

### 4.3 院校列表

桌面端每行依次展示：

1. 英国大学名称；
2. QS 名次与榜单年份；
3. THE 名次或区间与榜单年份；
4. 中国院校清单公开状态；
5. 规则适用范围；
6. 官方来源与最近内容更新时间。

手机端不强行保留宽表格，改为纵向卡片：大学名称与中国院校规则在上，QS/THE 使用两个紧凑的辅助标签放在下方。折叠清单仍在学校卡片内部展开。

### 4.4 排名显示状态

排名字段必须区分：

- 精确名次，例如 `42`；
- 并列名次，例如 `=42`；
- 官方区间，例如 `201–250`；
- 当期榜单未出现；
- 暂未完成核实。

“当期未上榜”和“暂未核实”不能共用同一种文案。

### 4.5 LBS

LBS 显示为：

- 目录类别：特色院校；
- QS 综合排名：—；
- THE 综合排名：—；
- 专项参考：QS 2026 商业与管理学科全球第 9；
- 说明：专门商学院，不参与综合大学目录排序。

专项排名只出现在 LBS 详情说明中，不与 QS/THE 综合排名混排，也不作为全站统一排序字段。

## 5. 数据结构

数据拆分为四个相互独立的层次，避免排名、学校身份和申请规则互相覆盖。

### 5.1 院校目录

保存稳定身份信息：

- 内部唯一标识；
- 中英文名称、简称和别名；
- 官方域名；
- 目录类别：`qs-directory` 或 `specialist`；
- 当前是否属于 QS 英国院校范围；
- 首次收录年份和最近一次目录核验年份。

院校身份不依赖某一年的排名。排名变化不会创建一所“新学校”。

### 5.2 排名记录

QS 与 THE 分开保存，每条记录包含：

- 院校唯一标识；
- 排名机构；
- 榜单名称；
- 榜单年份；
- 原始排名文本；
- 可排序的最低名次；
- 状态：精确、并列、区间、当期未上榜或暂未核实；
- 官方来源和核验日期。

保留原始文本可以正确显示 `=42` 和 `201–250`，可排序数值只服务于页面排序。

### 5.3 中国院校规则

继续保存：

- 中国本科院校规范名称与别名；
- 英国大学或学院的分档名称；
- 成绩要求；
- 全校、学院、专业或课程适用范围；
- 申请季；
- 官方来源；
- 内容摘要更新时间；
- 证据状态。

排名数据不得改变中国院校规则或匹配结果。

### 5.4 来源审查状态

每个来源独立保存：

- 最近检查时间；
- 最近成功检查时间；
- HTTP 状态和最终 URL；
- ETag、Last-Modified 或规范化内容指纹；
- 连续失败次数；
- 当前状态：正常、内容变化、访问异常或待复核。

来源检查时间与中文摘要更新时间分开，避免“每天检查”被误解成“每天都改了内容”。

## 6. 数据更新流程

### 6.1 排名年度更新

排名不参加每日抓取。QS 或 THE 发布新一版综合排名后：

1. 生成新的年度排名数据文件；
2. 核对英国院校身份、重名、并列名次和区间名次；
3. 追加新进入 QS 英国范围的院校；
4. 对未出现在当期 QS 的既有院校标记“当期未上榜”，不删除历史记录；
5. 将 THE 记录按稳定院校标识叠加到 QS 主目录；
6. 运行完整测试并通过预览页确认后再发布。

排名只保存网站展示所需的最小事实、年份、归属和官方来源，不镜像或重新发布完整榜单。若排名网站条款不允许自动收集，则使用经过核验的年度数据文件，不通过每日工作流绕过限制。

### 6.2 中国院校来源每日审查

GitHub Actions 每日运行一次：

1. 读取已经登记的大学及学院官方来源；
2. 以低频、保守方式检查链接和规范化内容指纹；
3. 没有变化时只更新后台审查结果，不修改摘要、不发布无意义提交；
4. 检测到内容变化时保留当前可信摘要，记录差异并标记待复核；下一次正常发布只允许更新“来源近期有变动”的状态提示，不能改写清单或摘要正文；
5. 新内容完成重新提取和规则校验后，才更新结构化事实、中文摘要和实际内容更新时间；
6. 单个来源失败不阻断其他来源或网站构建。

每日审查不调用人工智能或翻译 API，因此除现有工具使用外不产生额外服务费用。

## 7. 异常处理

- 单次超时、403、404 或服务器错误只记录后台状态，不修改公开内容。
- 同一来源连续三次每日审查失败后才标记为需要检查，减少偶发网络波动造成的误报。
- 重定向只有在最终地址仍属于该学校确认过的官方域名时才可登记。
- PDF 或网页结构改变且无法可靠提取时，保留原摘要并标记待复核，不自动猜测。
- 某所学校检查失败不影响其他学校、页面构建或 GitHub Pages 发布。
- 排名暂时无法核实时显示“暂未核实”，不能误写成“未上榜”。
- 任何异常都不能删除或覆盖上一版通过校验的中国院校清单。

## 8. 合规边界

- 只访问无需登录的大学、学院和排名机构公开页面。
- 不绕过验证码、登录、付费墙、访问控制或网站技术限制。
- 遵守 robots 指令、网站条款、合理访问频率和官方域名范围。
- 不复制完整排名表、大学网页或 PDF，只保存检索与展示所需的结构化事实、短摘要和来源链接。
- QS 和 THE 排名页面均显示清晰署名、榜单年份和官方来源。
- 排名数据使用前再次检查 [QS 条款](https://www.topuniversities.com/terms-conditions) 与 [THE 网站条款](https://www.timeshighereducation.com/website-terms-of-use)。

## 9. 测试策略

### 9.1 数据测试

- 当期 QS 英国院校范围覆盖测试；
- 唯一标识、别名和重名冲突测试；
- QS/THE 机构、榜单名称和年份必填测试；
- 精确、并列、区间、未上榜和未核实状态测试；
- 中国院校规则与排名数据相互隔离测试；
- LBS 只能属于特色院校且不能进入综合排名排序的测试。

### 9.2 搜索与页面测试

- 英国大学中英文名和简称搜索；
- 中国本科院校中英文名和别名搜索；
- 清单证据状态筛选；
- QS、THE 以及区间排名排序；
- 桌面宽表格、手机卡片和折叠清单测试；
- 官方来源和专业链接测试；
- GitHub Pages 子路径资源和链接测试。

### 9.3 自动审查测试

- 无变化时不修改网页数据、不生成发布提交；
- 内容变化时只生成审查状态和差异，不覆盖可信摘要；
- 404、403、超时、重定向和无文本 PDF 测试；
- 连续三次失败阈值测试；
- 单个来源失败时其他来源继续运行；
- 审查任务失败时生产网站仍可正常访问。

### 9.4 回归与发布测试

- 现有院校数据、中文搜索、折叠清单和来源显示回归测试；
- Astro 类型检查与静态构建；
- 预览分支桌面和手机视觉检查；
- 只有完整 CI 通过后才允许合并并发布 GitHub Pages。

## 10. 分阶段交付

1. 扩展院校与排名数据结构，同时兼容现有 29 所院校数据。
2. 收录当期 QS 榜单中的全部英国院校，完成名称、别名和官方入口核对。
3. 为主目录院校叠加当期 THE 综合排名。
4. 更新列表、筛选、排序与手机卡片布局，保留现有中国院校清单折叠内容。
5. 补充新院校的中国学历入口和公开清单状态；有明确清单的院校优先丰富。
6. 调整每日审查，使排名年度更新与申请来源每日检查彻底分离。
7. 在独立分支生成预览，完成数据、功能、视觉和自动审查验收后再上线。

## 11. 验收标准

- 当期 QS 世界大学排名中出现的全部英国院校都进入主目录。
- 每所主目录院校都有明确的 THE 名次、官方区间、当期未上榜或暂未核实状态。
- QS 与 THE 均显示正确榜单年份和来源。
- 没有中国院校公开清单的学校仍可搜索，并显示中性、可解释的状态。
- LBS 以特色院校展示专项排名，不参与综合大学排序。
- 现有中国院校清单、成绩要求、来源、折叠和中文搜索功能保持可用。
- 每日审查不自动覆盖摘要，网络或解析异常不影响生产网站。
- 完整测试、类型检查、静态构建和桌面/手机预览通过。
- 正式上线前由用户确认预览版本。

## 12. 非目标

- 不复制或重发 QS、THE 完整榜单；
- 不把 THE-only 院校加入 QS 主目录；
- 不将专项排名与综合排名混排；
- 不提供录取概率、资格保证、冲刺/保底或个性化选校判断；
- 不在本阶段建立全量硕士专业与逐专业申请要求数据库；
- 不引入付费抓取、翻译、排名、数据库或人工智能 API；
- 不依赖用户电脑全天运行。
