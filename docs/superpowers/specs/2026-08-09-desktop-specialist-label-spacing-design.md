# 桌面端特色院校标签间距修复设计

## 目标

修复桌面端“特色院校”胶囊标签与下方专业优势说明框左边框视觉重叠的问题，使两个元素之间有清晰留白。

## 范围

- 只调整宽度大于 800px 的桌面布局。
- 保留“特色院校”标签、红色说明框、链接、文字和现有网格结构。
- 移动端布局、普通院校卡片、排序、搜索和数据内容全部不变。

## 方案

根因是 `.specialist-detail` 在桌面样式中使用负上边距，将说明框向上拉到标签下边框附近。删除负间距，并为桌面端说明框提供小幅正上边距；现有移动端媒体查询继续把该间距重置为 `0`。

## 验证

1. 先增加会捕获桌面端负间距、同时保护移动端重置规则的失败测试。
2. 最小修改 CSS 使测试转绿。
3. 运行完整测试和构建。
4. 在 1440px 桌面预览中检查特色院校卡片，确认标签与说明框不再接触；同时在 390px 移动预览中确认布局没有改变、页面无横向溢出。
