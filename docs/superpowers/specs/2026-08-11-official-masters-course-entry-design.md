# 小英高校百科：硕士课程官网入口设计

日期：2026-08-11

## 目标

在现有 101 所英国大学目录中，为每所大学增加一个经过核验的官方硕士／研究生课程目录入口，帮助用户从中国院校规则直接进入大学官网查找专业。

本次只增加官网导航入口，不建立站内专业数据库，不抓取或翻译每个专业的申请要求。

## 已确认的界面方案

- 保留现有六列桌面排版、移动端卡片排版、排序、筛选、中国规则摘要、公开 List 和来源链接。
- 不新增“硕士专业”页面，不新增目录列，不移动大学名称、排名或中国规则内容。
- 在现有“来源 / 操作”区域中，把以下两类入口作为同级操作展示：
  - 现有中国硕士／研究生入学要求来源；
  - 新增的“查看全部硕士课程”官方入口。
- 新入口使用固定主文案“查看全部硕士课程”，次级文案“硕士专业官网入口”，并保留外链图标。
- 新入口只指向大学官方的 postgraduate course finder、graduate course directory 或最接近的完整研究生课程检索页，不指向大学首页、第三方聚合站或单个示例专业。

## 多来源院校处理

- 中国规则来源少于 3 条时，保持目前逐条展示方式。
- 中国规则来源达到 3 条时，默认聚合为“中国硕士入学要求（N 条）”。
- 用户点击聚合项后，在原“来源 / 操作”区域展开各条来源；每条仍显示原标签、范围、规则类型、链接状态和最近成功检查时间。
- 曼彻斯特大学按此规则显示为“中国硕士入学要求（3 条）”，其中保留校级、计算机课程和法学院三条来源。
- 聚合只改变默认展示，不删除、不改写任何既有来源或中国规则摘要。

## 移动端

- 沿用现有移动端卡片顺序和宽度。
- “中国硕士入学要求”与“查看全部硕士课程”在“来源 / 操作”区域纵向排列。
- 展开的多来源列表保持单列、自动换行，不产生横向滚动或单字竖排。

## 数据结构

- 新建独立的硕士课程入口数据集，以大学稳定 ID 为键，恰好覆盖当前 101 所目录大学。
- 每条记录至少包含：大学 ID、官方 URL、中文入口标签、页面范围、核验日期和来源状态 ID。
- 硕士课程入口与中国规则来源分开建模，不能混入中国规则的 sourceIds、规则状态统计或公开 List 统计。
- 公开目录构建时将一条硕士课程入口连接到对应大学；缺失、重复或大学 ID 不匹配均使测试失败。

## 官网核验标准

- 必须为 HTTPS 官方大学域名或经大学官网明确跳转的官方课程平台。
- 页面必须是研究生／硕士课程列表、课程搜索或课程目录入口。
- 优先选择同时覆盖授课型硕士和研究型硕士（包括 MPhil）的入口。
- 如果学校把授课型和研究型课程完全拆分且没有共同检索入口，使用官方研究生课程总入口；不得为了凑“一条链接”而指向不完整的单个专业页面。
- 逐校记录最终 URL、页面标题和可证明其课程目录性质的文字锚点。

## 每日检查

- 复用现有每日来源巡查，检查 101 个硕士课程入口的可访问性、最终跳转地址和内容变化。
- 每日检查只更新检查状态；网页变化进入待审核，不自动更换正式 URL，不改写中国规则或课程内容。
- 正常情况下界面不额外显示一行检查日期；入口异常时才显示简短警告，避免增加视觉噪声。
- 连续失败阈值、并发保护和 GitHub Issue 去重沿用现有巡查安全策略。

## 测试与验收

- 数据测试：101 条、大学 ID 一一对应、无重复、全部 HTTPS、全部属于允许的官方域名。
- 构建测试：公开大学目录中的每所大学恰好连接一条硕士课程入口，中国规则来源与统计保持不变。
- 交互测试：普通大学显示独立硕士入口；3 条及以上中国来源默认折叠、可由键盘展开、展开后来源无丢失或重复。
- 回归测试：现有六列标题、排名排序、筛选、中文院校反查、List 折叠和每日巡查语义不变。
- 浏览器验收：桌面检查帝国理工和曼彻斯特；390px 手机检查两类入口、曼大展开、无重叠和横向溢出；控制台无错误或警告。

## 不在本次范围

- 站内列出所有硕士专业。
- 抓取或翻译专业级成绩、语言、本科背景和中国学生要求。
- 自动判断申请资格或“可能适用”。
- 更改 QS／THE 排名、现有中国院校事实、规则摘要或 List 数据。
