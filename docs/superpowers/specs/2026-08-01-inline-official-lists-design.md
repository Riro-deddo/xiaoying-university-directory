# 英国大学卡片内嵌官方 List 设计

## 目标

让用户在“查英国大学”模式中直接查看本站已经可靠提取的中国本科院校 List，不必先切换到反向查询，也不必逐个打开大学官网寻找名单。

## 展示范围

- 只展示 `generated/requirements.json` 中已经通过来源登记、Schema 和解析保护条件的事实。
- 当前可展开的来源是 UCL（84 所）和爱丁堡大学（81 所）。
- 南安普顿大学虽登记为公开 List 来源，但解析模式仍是 `link-only`；页面只保留官方入口并显示“官网名单暂未稳定提取，本站暂不附表”。
- 其他没有结构化事实的来源不生成空名单，也不根据搜索相似度补齐内容。

## 页面交互

每个英国大学条目保持原有摘要行。若该校存在结构化事实，在条目下方增加原生 `<details>`：

- 摘要文案为“查看已收录院校 List（N 所）”；
- 默认折叠，避免首页首次加载时出现超长列表；
- 展开后显示来源名称、适用范围、申请季、最近提取日期和官方链接；
- 名单按规范中文校名排序，每行显示中文校名、官网原名、官方分组/等级，存在官方分数时再显示分数；
- 小屏使用卡片式行布局，不产生横向滚动条。

动态 `link-only` 的公开 List 来源显示一条中性说明和官方链接，不提供展开按钮。

## 数据流与安全边界

Astro 构建时加载院校目录、申请事实和已登记来源，按 `universityId` 与 `sourceId` 连接。名单与反向查询共用同一份生成数据，不新增第二份人工清单，也不在浏览器运行时抓取大学网页。

来源异常时，现有同步保护继续保留上一版可信事实；因此卡片展开内容与反向查询保持一致。页面不把“名单中存在/不存在”改写为申请资格结论。

## 测试与验收

- 数据连接测试：165 条事实都能连接到规范院校与正确来源；
- 页面测试：UCL 与爱丁堡出现数量正确的展开入口，南安普顿只显示暂未稳定提取说明；
- 浏览器测试：桌面和 320px 手机端可展开、阅读并关闭 List，无横向溢出；
- 回归测试：双向搜索、证据状态、完整测试和静态构建继续通过。

## 非目标

- 不为每所大学新建详情页；
- 不提供 CSV 下载；
- 不镜像完整大学网页或 PDF；
- 不把模糊匹配结果自动写入官方名单。
