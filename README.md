# 小英高校百科

一个面向中国学生的免费英国大学中国院校规则导航页。主目录覆盖 QS 2027 中出现的全部英国院校（93 所）；THE 2026 只作同校辅助展示，THE-only 院校不加入目录。伦敦商学院（LBS）作为专业院校保留，显示 QS 2026 商业与管理第 9，不伪造综合大学排名。项目把分散在大学官网的中国申请要求、公开院校名单和部分学院入口集中到一个页面。

网站支持两个方向的查询：

- 按英国大学查看公开状态、适用范围、申请季和官方来源；
- 按中国本科院校中文名查询 93 所 QS 2027 英国院校及 LBS 各自公开了什么证据。

每所大学另提供一条经核验的官方硕士课程目录入口，方便直接前往大学官网查找专业。

目录还显示每所大学已复核的官方硕士奖学金入口，或未发现公开入口的不可点击状态；可点击项仅用于导航到大学官网。

本站不判断申请资格、录取概率或“保底/冲刺”；排名只作信息参考。页面会区分院校准入限制、院校成绩分档、准入与成绩混合规则，以及未发现院校名单。名单外不一定不能申请；中国院校 List、分档和具体要求应以学校、学院、具体项目官网与招生部门答复为准。

## 数据范围与可信边界

- 目录范围来自 QS 2027 世界大学排名；THE 2026 是同一批院校的辅助信息。排名数据是按年度审核的版本化快照，不会随每日来源检查改写。
- 排名年份、本站内容更新时间和大学官网来源检查时间不是同一个日期；来源检查时间只表示最近一次读取或核验，不表示大学当天修改要求或人工改写规则。
- 只使用无需登录即可访问的大学官方来源，不使用论坛、机构或社交媒体作为结论来源。
- 中文院校名来自中国教育主管部门或院校官方页面；模糊搜索只提供候选，不会自动认定命中。
- Band、Tier、List 标题与分组名称保留官方原文，不把大学分组翻译成中国院校等级。
- 自动生成数据只保存结构化事实、内容哈希和时间，不镜像完整大学网页或文件。

当前覆盖情况可运行 `node scripts/report-source-coverage.mjs` 查看。并非每所英国大学都会公开一份可解析的中国本科院校名单；没有公开名单的学校仍保留其官方中国申请入口。

凡是已经通过解析保护条件并生成结构化事实的官方来源，页面都会在对应英国大学下方自动加入默认折叠的院校规则；它与按中国本科院校查询共用同一份数据，不维护第二份手工名单。大型官方名单按来源拆分为静态 JSON，用户首次展开该校面板时才读取；反向查询索引仅在切换到中国本科院校查询时读取。大型官方名单如果仍有重复记录、院校改名或中英文名称对应关系未解决，会先保留为官网直达链接，而不复制成可能不准确的本站名单。这是数据完整性边界，不是申请资格结论。

规则类型由人工核验官方文字后登记：院校准入限制表示名单直接影响资格；院校成绩分档表示名单决定成绩门槛；混合规则需要结合课程 Band 等条件阅读。若来源仅适用于部分学院，页面会明确标注，不能外推到整所大学。自动任务只记录来源页面的变化或异常，不会自行猜测规则含义或接受中国规则数据。

## 年度排名更新

年度排名由维护者人工更新。发布新版本时，更新版本化的 `src/data/rankings.json`、来源记录 `docs/data/ranking-sources.md` 和相应测试；再运行 `pnpm test:run` 与 `pnpm build` 后，有意地提交审核过的排名快照。年度排名更新与中国规则来源的接受路径相互独立。

## 每天来源审查

每天一次的 GitHub Actions 在 GitHub 托管运行，不需要个人电脑 24 小时开机。它不调用付费 API，也不会自动接受或改写已经确认的中国规则摘要。日常审查只会请求已登记的大学官网链接，并记录页面内容变化或访问异常：

1. 用 Lychee 低频检查已登记的官方链接；
2. 记录页面内容变化或访问异常；变化进入待审核，已接受数据保持不变。

`pnpm sync:sources` 仅用于人工确认大学官网来源变化后，接受并解析中国规则来源。运行后应检查差异、运行完整测试和构建，再有意地提交接受结果。机器人使用仓库自带的 `GITHUB_TOKEN`，不需要个人令牌或付费服务。

## 本地运行

需要 Node.js 22 和 pnpm。

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

完整验证：

```bash
pnpm test:run
pnpm build
node scripts/report-source-coverage.mjs
```

需要主动访问大学官网时再运行：

```bash
pnpm check:sources
pnpm sync:sources
```

## 主要数据文件

- `src/data/rankings.json`：QS 2027 与 THE 2026 的年度排名快照；来源和刷新规则见 `docs/data/ranking-sources.md`；
- `src/data/universities.json`：93 所 QS 目录院校、LBS 专业院校、公开状态和来源关联；
- `src/data/sources.json`：人工登记的官方入口、适用范围、规则核验页和解析保护条件；
- `src/data/institutions.json`：中国本科院校规范名称与可核验别名；
- `src/data/generated/requirements.json`：通过保护条件的官方名单事实；
- `src/data/generated/reverse-index.json`：可复现生成的反向查询索引；
- `src/data/status.json`：最近检查时间、健康状态和最终跳转地址。

## 成本

项目设计为公开 GitHub 仓库 + GitHub Pages + GitHub Actions，不依赖付费 API、数据库、分析、域名或服务器。是否持续为零成本取决于 GitHub 当时对公开仓库的免费政策与额度。
