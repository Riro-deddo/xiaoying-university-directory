# 小英高校百科

一个面向中国学生的免费英国大学中国院校规则导航页。第一版覆盖 28 所 QS 2027 世界前 200 英国大学 + 1 所专业院校（伦敦商学院）；专业院校不伪造 QS 综合排名。项目把分散在大学官网的中国申请要求、公开院校名单和部分学院入口集中到一个页面。

网站支持两个方向的查询：

- 按英国大学查看公开状态、适用范围、申请季和官方来源；
- 按中国本科院校中文名查询 28 所 QS 2027 世界前 200 英国大学 + 1 所专业院校各自公开了什么证据。

本站不判断申请资格、录取概率或“保底/冲刺”。页面会区分院校准入限制、院校成绩分档、准入与成绩混合规则，以及未发现院校名单。名单外不一定不能申请，最终要求以大学官网及招生部门答复为准。

## 数据范围与可信边界

- 目录范围来自 QS 2027 世界大学排名，快照记录于 2026 年 8 月 1 日。
- 只使用无需登录即可访问的大学官方来源，不使用论坛、机构或社交媒体作为结论来源。
- 中文院校名来自中国教育主管部门或院校官方页面；模糊搜索只提供候选，不会自动认定命中。
- Band、Tier、List 标题与分组名称保留官方原文，不把大学分组翻译成中国院校等级。
- 自动生成数据只保存结构化事实、内容哈希和时间，不镜像完整大学网页或文件。

当前覆盖情况可运行 `node scripts/report-source-coverage.mjs` 查看。并非每所英国大学都会公开一份可解析的中国本科院校名单；没有公开名单的学校仍保留其官方中国申请入口。

凡是已经通过解析保护条件并生成结构化事实的官方来源，页面都会在对应英国大学下方自动加入默认折叠的院校规则；它与按中国本科院校查询共用同一份数据，不维护第二份手工名单。大型官方名单按来源拆分为静态 JSON，用户首次展开该校面板时才读取；反向查询索引仅在切换到中国本科院校查询时读取。大型官方名单如果仍有重复记录、院校改名或中英文名称对应关系未解决，会先保留为官网直达链接，而不复制成可能不准确的本站名单。这是数据完整性边界，不是申请资格结论。

规则类型由人工核验官方文字后登记：院校准入限制表示名单直接影响资格；院校成绩分档表示名单决定成绩门槛；混合规则需要结合课程 Band 等条件阅读。若来源仅适用于部分学院，页面会明确标注，不能外推到整所大学。自动任务负责检查与提取，不会自行猜测规则含义。

## 每天自动更新

每天一次的 GitHub Actions 会按顺序完成：

1. 用 Lychee 低频检查已登记的官方链接；
2. 检查人工登记的规则核验页及关键文字，发生变化时等待人工重新核验；
3. 对明确启用解析的 HTML/PDF 来源进行自动提取；
4. 检查数量范围、事实 ID 删除比例、重复项、来源归属和 JSON Schema；
5. 异常时拒绝新结果、保留上一版可信数据，并创建或更新 GitHub Issue；
6. 重建中国院校反向索引，运行完整测试和静态构建；
7. 只提交通过保护条件的数据，再触发只读 CI；
8. GitHub Pages 只发布该次 CI 实际验证过的同一提交。

机器人使用仓库自带的 `GITHUB_TOKEN`，不需要个人令牌或付费服务。

## 本地运行

需要 Node.js 22 和 pnpm。

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

完整验证：

```bash
pnpm test:run
pnpm build
node scripts/report-source-coverage.mjs
```

需要主动访问大学官网时再运行：

```bash
pnpm check:sources
pnpm sync:sources
```

## 主要数据文件

- `src/data/qs-2027-top-200-uk.json`：固定的 28 所大学范围；
- `src/data/universities.json`：大学名称、排名、公开状态和来源关联；
- `src/data/sources.json`：人工登记的官方入口、适用范围、规则核验页和解析保护条件；
- `src/data/institutions.json`：中国本科院校规范名称与可核验别名；
- `src/data/generated/requirements.json`：通过保护条件的官方名单事实；
- `src/data/generated/reverse-index.json`：可复现生成的反向查询索引；
- `src/data/status.json`：最近检查时间、健康状态和最终跳转地址。

## 成本

项目设计为公开 GitHub 仓库 + GitHub Pages + GitHub Actions，不依赖付费 API、数据库、分析、域名或服务器。是否持续为零成本取决于 GitHub 当时对公开仓库的免费政策与额度。
