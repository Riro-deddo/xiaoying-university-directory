# 小英高校百科

一个面向中国学生的免费英国大学官方 List 导航页。它把大学公开的中国申请要求、院校名单和学院例外入口集中到一个可搜索页面，但不判断录取资格或录取概率。

## 本地运行

需要 Node.js 22 和 pnpm。

```bash
corepack enable
pnpm install
pnpm dev
```

验证：

```bash
pnpm test:run
pnpm build
pnpm check:sources
```

## 数据原则

- 只使用公开的大学官方来源。
- “未发现公开 List”或“待确认”不等于学校不接受申请。
- 中文解释不能冒充官方原文；无法完全对应时保留官方英文术语。
- 自动任务只更新 `src/data/status.json`，不会改写人工总结。
- 不绕过登录、验证码、付费墙或网站技术限制，不镜像完整页面和文件。

最终申请要求以大学官网及招生部门答复为准。

## 成本

项目设计为公开 GitHub 仓库 + GitHub Pages + GitHub Actions，不依赖付费 API、数据库、分析、域名或服务器。是否持续为零成本取决于 GitHub 当时对公开仓库的免费政策与额度。

## 状态

当前数据是用于验证页面和流程的首批记录，不代表 QS 2027 英国前 100 完整名单。公开发布前必须逐校补齐并核验。

许可证将在首次公开发布前确定；在此之前请勿将仓库内容视为已授予再分发许可。
